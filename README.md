Quick start:
1. Inspect the schemas in `schema/` and adjust if needed.
2. Regenerate or inspect `data/curated_train.jsonl` (generated by `scripts/generate_dataset.py`).

To regenerate the dataset locally:

```powershell
python scripts/generate_dataset.py
```

To evaluate responses after collecting model outputs (one response per line aligned with your held-out ground truth):

```powershell
python scripts/eval_score.py --ground_truth data/curated_train.jsonl --responses eval/base_responses.txt --out eval/baseline_scores.csv
```

All-in-one pipeline
-------------------
Run the full local pipeline (generate dataset, create heldout, populate responses, evaluate):

```powershell
python scripts/run_pipeline.py
```

Deliverables included
---------------------
- `data/curated_train.jsonl`: synthetic training examples
- `data/heldout_test.jsonl`: 20-example held-out test
- `data/curation_log.md`: simple curation log
- `eval/base_responses.txt`: placeholder model responses (ground-truth)
- `eval/baseline_scores.csv`: evaluation CSV output
- `scripts/run_pipeline.py`: runner to reproduce results locally

LlamaFactory fine-tuning steps (high level):
- Launch `llamafactory-cli webui` and open Fine-Tune.
- Upload `data/curated_train.jsonl`, choose LoRA, and set parameters from `training_config.md`.
- Screenshot the config panel and save to `screenshots/training_config.png`.
- Train and save the loss curve to `screenshots/loss_curve.png`.

Notes on limitations:
- This repository contains synthesized training examples and templates. Actual model training and inference must be run in LlamaFactory (web UI) or Open WebUI; this environment cannot perform the web UI training steps for you.
